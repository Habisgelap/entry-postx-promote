One X post promoting make.fun's make-your-own-bounty post: a quote of make.fun's post with an original photo, make.fun's link and my play code in its text. The post itself is the entry — this repo only hands in the post's address through POST.json, and main.ts copies POST.json to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
